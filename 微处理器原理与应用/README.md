# 微处理器原理与应用

本课程只有回忆版试卷，但是和考题几乎没什么区别。考试之前可以相互问问别的专业的同学老师划了什么重点。这门课还是很依赖某位老师画的重点的(笑

正如总readme所言，本课是一门对背诵要求很高的课。建议复习这门课的时候和同学一起背诵，方便互相查出来有没有什么错误。本课如果没有加入微机原理的内容，那就是51单片机和STM32两大块内容，分两个老师上。51单片机重点是各寄存器的功能、触发方式，32的重点更侧重标准库的使用（虽然实践课大家都在用HAL库就是了233）。当然，两种单片机的代码一定要搞懂，书上的示例代码基本就是考试会考的范围，顶多增加点接口，不会有更难的内容。

考试题型分为填空简答、编程和改错题，每个题型各两道大题，分别考51和32两大块内容。除此之外还会考一些C语言的知识点（例如一个八位数字如何取它的高四位和第四位）。
